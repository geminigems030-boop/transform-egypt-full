# TransforM Egypt - Migration & Deployment Guide

This project has been successfully migrated from Replit to a standard Vite + Node.js structure.

## 1. Prerequisites
- **Node.js**: v20 or higher
- **pnpm**: `npm install -g pnpm`
- **Database**: A Supabase PostgreSQL instance

## 2. Database Setup (Supabase)
1. Get your **Transaction Connection String** from Supabase Settings.
2. From the root of this project, run:
   ```bash
   export DATABASE_URL="your_supabase_connection_string"
   pnpm --filter @workspace/db run drizzle-kit push
   ```

## 3. Backend Deployment (Railway)
1. Connect this GitHub repo to **Railway**.
2. Create a new Service and select this repo.
3. Set the **Root Directory** to `artifacts/api-server`.
4. Add all environment variables (Meta, Anthropic, Twilio, etc.).
5. Railway will automatically detect the `package.json` and start the server.

## 4. Frontend Deployment (Vercel)
1. Connect this GitHub repo to **Vercel**.
2. Set the **Root Directory** to `artifacts/transform-egypt`.
3. Vercel will use the `vercel.json` already in that folder.
4. Add these environment variables:
   - `DATABASE_URL`: (Same as above)
   - `VITE_TIKTOK_PIXEL_ID`: (Optional)

## 5. Domain (Cloudflare)
1. Update your **CNAME** for `transform-egypt.com` to point to the Vercel deployment URL.
2. Update your **A record** for `api.transform-egypt.com` (if used) to point to the Railway service URL.
