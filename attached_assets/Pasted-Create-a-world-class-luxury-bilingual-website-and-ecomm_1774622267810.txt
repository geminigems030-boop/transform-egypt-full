ANIMATION PHILOSOPHY

Principles:
• Subtle and purposeful - enhance luxury, never distract
• Smooth 60fps animations
• Respect user's motion preferences (prefers-reduced-motion)
• Progressive enhancement (works without JS)

Animation Library: Framer Motion

Key Animations:

1. Scroll Animations:
   • Fade-in on scroll (opacity 0 → 1, translateY 20px → 0)
   • Stagger children by 100ms for card grids
   • Trigger when element is 20% in viewport

2. Hero Parallax:
   • Background image moves slower than foreground (10-20% speed)
   • Subtle, elegant, not dizzying

3. Hover States:
   • Buttons: 300ms transition
   • Cards: lift effect (translateY -8px, shadow increase)
   • Images: subtle zoom (scale 1.05, 500ms)

4. Page Transitions:
   • Fade between routes (200ms)
   • Smooth, seamless navigation

5. Loading States:
   • Skeleton screens (not spinners)
   • Gold shimmer effect for loading content

Example Framer Motion Code:
```javascript
const fadeInUp = {
  initial: { opacity: 0, y: 20 },
  animate: { opacity: 1, y: 0 },
  transition: { duration: 0.6, ease: "easeOut" }
};

Performance: • Prioritize mobile performance (see Performance Requirements) • Minimize JavaScript (heavy scripts slow mobile) • Optimize images aggressively • Use system fonts when possible (faster loading)

SECURITY & PRIVACY
─────────────────════════════════════────────────────────────────
SSL Certificate: • HTTPS for entire site (not just checkout) • Valid SSL certificate (Let's Encrypt or commercial) • Redirect HTTP to HTTPS automatically
Data Protection: • GDPR-compliant (even if not EU-based, best practice) • Clear privacy policy (what data collected, how used, how protected) • Cookie consent banner (if using cookies) • User data encryption (passwords, payment info) • Secure database (not publicly accessible)

Backups: • Automated daily backups (database + files) • Offsite backup storage (not same server) • Test restore process regularly
Updates: • Keep Next.js, React, and all dependencies updated • Security patches applied promptly • Monitor for vulnerabilities (Dependabot, Snyk)
